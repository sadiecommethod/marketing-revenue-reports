How to add a new report
Quick Guide

1. Upload the file. Place the HTML report in the matching brand subfolder in your repo: roost/, the-pinch/, or the-nickel/.

2. Add a link. Open index.html, find the brand's <!-- ADD ... REPORTS --> comment, and paste a new <a> line using the pattern in the comment above it.

3. Remove the "no reports" placeholder if it's the first one for that brand (delete the <div class="report-empty"> line).

4. Commit & push. GitHub Pages will update within ~30 seconds.
